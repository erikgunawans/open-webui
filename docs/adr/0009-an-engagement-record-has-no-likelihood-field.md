# An engagement record has no likelihood field

Engagement records hold the observable stage and the artefact evidencing it. There is deliberately
**no field** for likelihood, probability of closing, expected close date, or confidence.

`~/jup/kb/partners.md` already imposes the rule on the strategy assistant — *"Do not speculate about
any counterparty's position, willingness, or timeline… Assume nothing."* This makes it a property of
the schema rather than an instruction a prompt can drop.

Every business-development tool in existence has a probability column, so the next engineer will read
its absence as an oversight and add one. It is not an oversight: a forecast that cannot be evidenced
is the same failure mode D11 prohibits for figures, in a second domain.

## Consequences

The dashboard states where engagements **stand**, never whether they will **close** — and says so, as
named non-coverage. Judgement about a counterparty's intent stays with the director and in meeting
notes, outside the system of record.
