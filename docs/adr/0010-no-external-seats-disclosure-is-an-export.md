# No external seats; disclosure to partners is a generated export

Capital and EPC partners never receive access to this system. `~/jup/kb/partners.md` Channel 2 names
*"a transparent dashboard"* among the proof shown to IPPs, EPC firms and ESG funds; that is satisfied
by a **point-in-time export** — gate status plus RUED alignment per project, generated from the same
gate assessments and published as a deliverable beside the Master Plan and the board deck, under
D12's existing rule that HTML is source and PDF is derived.

## Considered options

- **External read-only seats, scoped per counterparty.** Breaks ADR-0001's fifty-user ceiling on
  first contact with a fund's deal team, and puts every counterparty one scoping bug away from
  reading another's engagement record — Pertamina seeing what Danantara is doing.
- **A separately hosted public-facing view fed from the same data.** The export, plus a hosting
  surface and an auth gate to defend, for no gain over a PDF.

## Consequences

Each disclosure is a deliberate act carrying a date and a name — the same shape as admitting a
document to the voice scope (ADR-0006).
