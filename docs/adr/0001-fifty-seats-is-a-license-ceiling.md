# Fifty end users is a license ceiling, not a capacity target

Open WebUI's LICENSE clause 4 (`LICENSE:28` in this fork) permits altering or removing Open WebUI
branding only where total end users do not exceed **fifty (50) within any rolling thirty (30) day
period**, absent a written enterprise agreement. We white-label this deployment for PT JUP, so the
first-year population — PMO, HSE and project leads — is held deliberately below fifty.

Crossing the line degrades nothing technically. It converts a free branding decision into a
per-seat purchase negotiation at an unpublished price, sold only to registered entities.

## Consequences

Board members and commissioners consume output — briefings, dashboard links — without holding
seats. Any proposal to widen access is a licensing decision before it is a capacity decision.
