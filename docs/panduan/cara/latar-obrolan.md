# Mengatur Latar Obrolan

Panduan ini menjelaskan cara memilih latar di belakang obrolan: putih polos atau pola JUP.

## Langkah

1. Klik nama atau foto profil Anda di bilah samping kiri, lalu pilih **Pengaturan**.
2. Pilih tab **Antarmuka**.
3. Cari baris **Latar Obrolan**.
4. Klik nilai di sebelah kanannya untuk berganti antara **Putih Polos** dan **Pola JUP**.

Perubahan langsung tersimpan. Pilihan bawaan adalah **Putih Polos**.

## Yang perlu diketahui

- Pilihan ini hanya berlaku untuk akun Anda.
- Baris **Gambar Latar Belakang Obrolan** di bawahnya adalah pengaturan terpisah untuk memakai gambar Anda sendiri.
