# Mengajukan Dokumen ke Basis Pengetahuan

Panduan ini menjelaskan cara mengajukan dokumen agar, setelah ditinjau admin, Asisten JUP dapat memakainya untuk menjawab.

> **Butuh akses:** grup **Kontributor KB**.

## Langkah

1. Klik **Tinjauan Pengetahuan** di bilah samping kiri, atau kartu **Tinjauan Pengetahuan** di halaman utama.
2. Pada bagian **Ajukan dokumen**, klik kolom **Dokumen** dan pilih berkas dari komputer Anda.
3. Jika perlu, isi **Catatan untuk peninjau (opsional)**, misalnya asal dokumen atau bagian yang paling penting.
4. Klik **Ajukan untuk ditinjau**. Tombol berubah menjadi **Mengunggah dan membaca dokumen…**, lalu **Mengajukan…**.
5. Setelah muncul pesan **Terkirim. Admin akan meninjaunya.**, pengajuan Anda tampil di daftar **Pengajuan saya**.

## Jenis berkas yang diterima

Hanya dokumen teks: **md, txt, pdf, docx, pptx, xlsx, csv**. Gambar, audio, dan video tidak diterima karena isinya tidak dapat dibaca dan dijamin oleh peninjau. Catatan untuk peninjau paling panjang 1.000 karakter.

## Status pengajuan

| Status                  | Artinya                                                                               |
| ----------------------- | ------------------------------------------------------------------------------------- |
| **Menunggu peninjauan** | Admin belum memutuskan.                                                               |
| **Disetujui**           | Dokumen masuk ke koleksi _JUP Staff Contributions_ dan dapat dipakai Asisten JUP.     |
| **Ditolak**             | Dokumen tidak dipakai. Alasan penolakan tampil di bawah pengajuan sebagai **Alasan**. |

## Yang perlu diketahui

- Dokumen yang disetujui dapat dipakai untuk menjawab pertanyaan **semua** pengguna Asisten JUP, bukan hanya Anda. Jangan mengajukan dokumen yang hanya boleh dibaca kalangan terbatas.
- Hanya admin yang meninjau pengajuan.
- Jika Anda melihat **Anda tidak memiliki akses ke antrean tinjauan**, akun Anda belum masuk grup Kontributor KB. Hubungi admin None-JUPe.
- Untuk sekadar bertanya tentang satu dokumen tanpa menambahkannya ke basis pengetahuan, cukup lampirkan dokumen di obrolan. Lihat [Melampirkan Dokumen dan Bertanya](lampirkan-dokumen.md).
