# Peta Menu

Halaman ini mencantumkan nama menu dan tombol None-JUPe persis seperti yang tampil dalam Bahasa Indonesia.

Beberapa label belum diterjemahkan dan tampil dalam bahasa Inggris; label seperti itu ditulis apa adanya di bawah. Menu yang bergantung pada akses khusus ditandai dengan grupnya (lihat [Akses dan Grup](akses-dan-grup.md)).

## Bilah samping kiri

| Item                         | Fungsi                                                                                                                   | Muncul untuk                           |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------ | -------------------------------------- |
| **Obrolan Baru**             | Membuka halaman utama untuk obrolan baru.                                                                                | Semua                                  |
| **Cari**                     | Mencari obrolan Anda.                                                                                                    | Semua                                  |
| **Ruang Pimpinan**           | Membuka Ruang Pimpinan.                                                                                                  | Ruang Pimpinan — uji                   |
| **Tinjauan Pengetahuan**     | Mengajukan dokumen ke basis pengetahuan; bagi Legal, juga antrean **Kartu Kontrak**.                                     | Kontributor KB, Kontrak — Legal, admin |
| **Portofolio**               | Status portofolio proyek.                                                                                                | Admin saja                             |
| **Folder** / **Folder Baru** | Mengelompokkan obrolan.                                                                                                  | Semua                                  |
| **Disematkan**               | Obrolan yang Anda sematkan.                                                                                              | Semua                                  |
| **Obrolan**                  | Riwayat obrolan, dikelompokkan **Hari ini**, **Kemarin**, **7 hari sebelumnya**, **30 hari sebelumnya**, lalu per bulan. | Semua                                  |
| Nama atau foto profil Anda   | Membuka menu pengguna.                                                                                                   | Semua                                  |

### Menu tiga titik pada setiap obrolan (**Lainnya**)

**Berbagi**, **Unduh** (**Ekspor obrolan (.json)**, **Teks biasa (.txt)**, **Dokumen PDF (.pdf)**), **Ganti nama**, **Tandai belum dibaca**, **Sematkan** / **Lepas sematan**, **Kloning**, **Pindahkan**, **Arsipkan**, **Hapus**.

## Menu pengguna

Diakses dengan mengklik nama atau foto profil Anda.

| Item                          | Fungsi                            |
| ----------------------------- | --------------------------------- |
| **Perbarui status Anda**      | Menulis status singkat di profil. |
| **Bantuan** → **Papan ketik** | Daftar pintasan papan ketik.      |
| **Pengaturan**                | Membuka pengaturan akun.          |
| **Keluar**                    | Keluar dari None-JUPe.            |

Admin melihat item tambahan seperti **Panel Admin** dan **Playground**.

## Pengaturan

Tab yang tampil untuk akun staf:

| Tab                         | Isi yang relevan                                                                                                     |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Umum**                    | **Tema**, **Bahasa**.                                                                                                |
| **Antarmuka**               | **Latar Obrolan** (**Putih Polos** / **Pola JUP**), **Gambar Latar Belakang Obrolan**, dan pengaturan tampilan lain. |
| **Pemberitahuan**           | Pemberitahuan aplikasi.                                                                                              |
| **Papan ketik**             | Pintasan papan ketik.                                                                                                |
| **Personalisasi**           | **Memori**: sakelar, **Saved Memories**, **Actions** → **Menambahkan Memori** / **Menghapus memori**.                |
| **Audio**                   | Pengaturan suara.                                                                                                    |
| **Kontrol Data**            | Pengelolaan data obrolan.                                                                                            |
| **Penggunaan**              | Ringkasan pemakaian.                                                                                                 |
| **Obrolan yang Diarsipkan** | Obrolan yang Anda arsipkan.                                                                                          |
| **Akun**                    | Profil; bagian **WhatsApp** (**Hubungkan WhatsApp**, **Putuskan**) hanya untuk grup Kanal — uji.                     |
| **Tentang**                 | Informasi versi.                                                                                                     |

## Halaman utama

| Item                                                      | Fungsi                                                                                                                           |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Kolom tanya **Lampirkan dokumen atau ajukan pertanyaan…** | Tempat menulis pertanyaan.                                                                                                       |
| **Pengetahuan JUP**                                       | Menuliskan "Apa kata basis pengetahuan JUP tentang ".                                                                            |
| **Kontrak**                                               | Menuliskan "Carikan kartu kontrak untuk ".                                                                                       |
| **Ruang Pimpinan**                                        | Menuliskan "Dari Ruang Pimpinan, rangkum ". Hanya untuk grup Ruang Pimpinan — uji.                                               |
| **Lainnya**                                               | Menampilkan topik **Mengetahui:** **Strategi JUP**, **Portofolio proyek**, **Mitra**, **Gas & RUED**, beserta tanggal pembaruan. |
| Kartu **Area JUP** di bawah kolom tanya                   | Pintasan **Ruang Pimpinan**, **Tinjauan Pengetahuan**, atau **Portofolio** sesuai akses Anda.                                    |

## Menu kolom tanya

Tombol **+** (keterangan **Lainnya**) di kolom tanya:

| Item                      | Keterangan                                             |
| ------------------------- | ------------------------------------------------------ |
| **Unggah File**           | Mengunggah berkas dari komputer.                       |
| **Ambil**                 | Mengambil foto dengan kamera (perangkat seluler).      |
| **Lampirkan Halaman Web** | Tidak tersedia untuk staf.                             |
| **Lampirkan Berkas**      | Memakai lagi berkas yang pernah Anda unggah.           |
| **Lampirkan Pengetahuan** | Melampirkan koleksi pengetahuan yang dapat Anda akses. |
| **Obrolan Rujukan**       | Merujuk obrolan Anda yang lain.                        |

Tombol panggilan (keterangan **Mode suara**) muncul di kolom tanya hanya untuk grup Suara — uji, saat kolom tanya kosong.

## Kartu persetujuan

| Label                    | Arti                                             |
| ------------------------ | ------------------------------------------------ |
| **Izinkan _nama alat_?** | Judul kartu persetujuan.                         |
| **Panggilan Eksternal**  | Kelas risiko tindakan yang menunggu persetujuan. |
| **Izinkan** / **Tolak**  | Menjalankan atau membatalkan tindakan.           |

Lihat [Menyetujui atau Menolak Panggilan Eksternal](../cara/menyetujui-panggilan-eksternal.md).
