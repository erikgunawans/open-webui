# Berkas dan Batas

Halaman ini mencantumkan jenis berkas, batas ukuran dan jumlah, serta batas waktu yang berlaku di None-JUPe.

## Berkas

| Konteks                            | Jenis berkas                                                 | Batas                                                                                                       |
| ---------------------------------- | ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| Lampiran obrolan (**Unggah File**) | Dokumen umum seperti PDF, Word, Excel, PowerPoint, dan teks. | Ditetapkan admin di server; belum tercantum di panduan ini.                                                 |
| Lampiran halaman web               | —                                                            | Tidak tersedia untuk staf.                                                                                  |
| Pengajuan ke basis pengetahuan     | md, txt, pdf, docx, pptx, xlsx, csv                          | Catatan untuk peninjau paling panjang 1.000 karakter.                                                       |
| Draf Word buatan asisten           | .docx                                                        | 16 templat JUP; selalu berstatus Draf.                                                                      |
| Draf Excel buatan asisten          | .xlsx                                                        | Paling banyak 10 lembar kerja, 5.000 baris per lembar, nama lembar paling panjang 31 karakter; tanpa rumus. |
| Draf PowerPoint buatan asisten     | .pptx                                                        | Satu sampul ditambah paling banyak 29 slide; teks yang melebihi kotaknya ditolak.                           |
| Lampiran lewat WhatsApp            | —                                                            | Belum didukung; unggah lewat aplikasi web.                                                                  |

## Batas waktu

| Hal                                       | Batas                                                                           |
| ----------------------------------------- | ------------------------------------------------------------------------------- |
| Kartu persetujuan **Panggilan Eksternal** | 10 menit sejak kartu tampil; setelah itu tindakan dibatalkan.                   |
| Kode penghubung WhatsApp                  | 10 menit, sekali pakai.                                                         |
| Sesi masuk                                | Sekitar 1 jam; setelah itu muat ulang halaman.                                  |
| Jawaban lewat WhatsApp                    | Jika belum selesai dalam 120 detik, Anda menerima tautan ke jawabannya.         |
| Percakapan WhatsApp                       | Pesan masuk ke obrolan yang sama selama obrolan itu aktif dalam 8 jam terakhir. |
| Panggilan GPT-Live                        | Sekitar 1 jam per panggilan.                                                    |
| Penyimpanan suara oleh OpenAI             | Hingga 30 hari.                                                                 |
