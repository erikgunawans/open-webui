# Briefing JUP (Bahasa Indonesia)

This skill writes a briefing for a director or commissioner. Keep it to one screen and put the most important point first.

## Structure

1. **Inti** (1–2 sentences): the bottom line. What the reader needs to know or decide.
2. **Posisi saat ini** (current position): the facts from the knowledge base and the records, including the gate status if it is relevant. Cite the source file in parentheses.
3. **Angka** (figures): only figures found in the knowledge base. Leave this section out if no figures are needed. The tier rule is stated here in full, because a skill this one refers to is not loaded with it:
   - Put exactly one tier label right after every figure: Tier 1 · FAKTA, Tier 2 · POTENSI or Tier 3 · ILUSTRATIF.
   - Every gas rupiah figure says "revenue, bukan margin".
   - Never add, compare or rank figures from different tiers.
   - Every figure carries its condition next to it, here and not only in section 4.
4. **Yang belum pasti** (what is uncertain): named non-coverage. Always include the ones that apply:
   - the 5 mmscfd allocation is not secured (G1);
   - the WTP fold-out is pending;
   - gas figures are revenue, not margin;
   - market sizing is illustrative;
   - the Rp 10 miliar SPBG reactivation cost assumes the idle stations can be revived, and there is no technical audit yet.
5. **Keputusan / langkah berikut** (decision / next step): only if the record names one. Never guess a partner's response.

## Language

- Use formal, direct Indonesian: *Anda* when addressing the reader, no filler, no marketing tone.
- Keep business terms in English: capex, OPEX, NPV, IRR, offtake, stage-gate, fold-out, B-to-G, KSO, PKS.
- Use standard Indonesian for status words: secured = "terkomitmen" or "diamankan", pending = "belum final", not committed = "belum terkomitmen". Never coin a word such as "disekurkan".
- Use Indonesian number formatting: Rp 63,3 miliar and 48,6%.
- Write institution names exactly as they appear in the record: SKK Migas, PGN/Pertagas, PLN, Pelindo, Transjakarta.
- If the knowledge base doesn't cover a point, write "belum ada di basis pengetahuan" (not yet in the knowledge base). Never fill the gap from general knowledge.
