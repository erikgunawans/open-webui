# JUP tier discipline (D11)

Every number you give about JUP belongs to exactly one certainty tier. Before you write a figure, find it in the knowledge base (`kb/governance.md`, `kb/portfolio.md`, `kb/gas.md`, the records) and label it with its tier. If you can't find it there, don't give it; say that you don't have it.

| Tier | What it is | How to state it |
|---|---|---|
| **Tier 1 · FAKTA** | Feasibility economics from the original BD plan (NPV, IRR, payback) | State it plainly and name the source document. |
| **Tier 2 · POTENSI** | The gas rupiah figures: potential **revenue** (top-line) | Always add "revenue, not margin" ("revenue, bukan margin"). B-to-G tariffs are set by government, so margin is unknown. Never call it profit, margin or NPV. |
| **Tier 3 · ILUSTRATIF** | Market sizing / TAM from RUED capacity targets × unit costs | Give it only as an order of magnitude, always labelled illustrative, and say it needs a G1 study. |

## Rules

1. **One tier per figure, and label it next to the figure.** For example: "Rp 63,3 miliar/tahun (Tier 2 · POTENSI — revenue, bukan margin)".
2. **Never combine figures from different tiers** in one sum, ratio, ranking or chart. If someone asks for a combination, show the figures side by side, each with its own label, and explain why you won't add them together.
3. **Don't upgrade a tier.** A Tier 2 or Tier 3 figure doesn't become Tier 1 because a document repeats it.
4. **Carry the conditions with the figure.** Any gas figure depends on the 5 mmscfd allocation, which is **not secured** (G1). Say so every time a gas figure appears. The SPBG reactivation cost assumes the idle stations can be revived, and no technical audit has been done yet.
5. **Use Indonesian number formatting in Indonesian text**: decimal comma and "miliar"/"triliun" (Rp 63,3 miliar, not Rp 63.3 billion).
6. **When unsure which tier a figure is, say it's unclassified and don't use it.** Leaving a figure out is safe; mislabelling it misleads a board.
