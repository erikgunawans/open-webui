`SectorIcon` renders one of the five business-line marks from the Graphic Standard Manual. These are brand assets, not UI icons — use them at 48px and up.

```jsx
<SectorIcon sector="gas" size={72} showLabel tone="blue" />
```

Sectors: `solar`, `listrik`, `gas`, `air`, `parkir`. Tones: `ink` (Rich Black), `white`, `green`, `blue` — the four the identity allows.
